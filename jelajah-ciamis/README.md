# Jelajah Ciamis

Jelajah Ciamis is an information website developed to introduce the tourism, culture, history, and local businesses of Ciamis Regency.

## Technologies
- HTML
- CSS
- JavaScript

## Features
- Tourism information
- Local culture and traditions
- Local business information
- Search and category filtering
- Responsive website design
