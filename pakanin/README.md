# PAKANIN – Fish Feed Recommendation Application

PAKANIN is a Python-based desktop application designed to help fish farmers estimate daily fish feed requirements and provide feeding recommendations based on fish species and farming conditions.

The application aims to simplify feed calculations and provide useful information to support more efficient fish farming management.

## Project Overview

Determining the appropriate amount of fish feed is important for maintaining fish growth and reducing feed waste. PAKANIN provides a simple application that helps users calculate daily feed requirements based on input data and selected fish species.

## Key Features

- **Daily Feed Calculator:** Estimates daily feed requirements based on user input.
- **Fish-Based Recommendations:** Provides feeding recommendations for different fish species.
- **Fish Information:** Displays information about supported fish species.
- **Input Validation:** Checks user input to support accurate calculations.
- **Interactive Navigation:** Provides an easy-to-use desktop interface.

## Supported Fish Species

- Catfish (Lele)
- Tilapia (Nila)
- Gourami (Gurame)
- Silver Barb (Bawal)
- Mozambique Tilapia (Mujair)

## Application Architecture

The application uses the Model-View-Controller (MVC) approach:

1. **Model (`PakanModel`):** Manages fish data, feeding recommendations, and calculation processes.
2. **View (`PakanView`):** Handles the graphical user interface and application navigation.
3. **Controller (`PakanController`):** Connects user input with application logic and displays the results.
