# SWIFT – Smart Water Integrated Flow and Turbidity Technology

SWIFT is an IoT-based water monitoring project developed to monitor water flow and turbidity in the DTEDI environment.

The project aims to provide information about water usage and water quality through sensor integration and a monitoring system.

## My Contribution
- Assisted in the IoT system implementation.
- Designed the system network topology.
- Worked with ESP32 and water flow and turbidity sensors.
- Explored data monitoring using Blynk.
